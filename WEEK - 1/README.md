# Week 1 - SecureBank Account Fundamentals

## Objective

Build the basic in-memory banking ledger for the SecureBank backend development project.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Close Account
- Invalid Account Handling
- Insufficient Balance Handling
- Invalid Amount Validation

## Concepts Used

- Python Dictionaries
- Dataclasses
- Functions
- Exception Handling
- Custom Exceptions
- While Loop
- CLI Input/Output
